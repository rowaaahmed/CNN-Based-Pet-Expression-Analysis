# CNN-Based-Pet-Expression-Analysis
The objective of this project is to develop an effective image classification system for recognizing and classifying pets’ facial expressions. To accomplish this, several well-established deep convolutional neural network architectures are designed and implemented, including VGG, ResNet, Inception, MobileNet, and DenseNet. Each architecture is trained on the target dataset, enabling a comparative evaluation of their performance in terms of classification accuracy, generalization capability, and computational efficiency.

After the training phase, the models are systematically evaluated to identify the best-performing architecture. This selected model is then further improved using transfer learning, by incorporating pretrained weights from large-scale ImageNet models. Fine-tuning the pretrained network on the pets’ facial expression dataset aims to enhance classification performance, accelerate convergence, and mitigate overfitting, especially when working with limited domain-specific data. Through this approach, the project highlights both the strengths of modern deep learning architectures and the practical benefits of transfer learning in real-world image classification applications.
